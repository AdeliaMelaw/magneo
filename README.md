# Magneo

React + Vite rebuild for Magneo's WordPress-to-React migration.

## What is included

- Claude-designed React homepage
- Services hub page
- Contact page
- Industry hub templates for law, finance, healthcare, and tech
- Dynamic service-detail template for all `/services/:slug` routes
- Placeholder pages for preserved non-blog SEO routes
- SEO helper for title, description, canonical, Open Graph, Twitter, and JSON-LD
- Vercel SPA rewrite config

## Development

```bash
npm install
npm run dev
npm run build
```

Blog content is intended to remain connected from WordPress later.
